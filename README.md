# FreeMyMemory — downloads

This repository holds the **downloads** of FreeMyMemory, a free Windows app that shows what is using your PC's memory and helps you free it safely. Only the program file is published here. To learn more, see **https://freemymemory.com**.

There are no downloads yet. The first release is coming soon.

## Download

Each release lists one file, `FreeMyMemory.exe`, and its SHA-256 checksum. Always take a download from a release on this page or from freemymemory.com, never from anywhere else.

## Check that your download is genuine

Open Command Prompt in the folder where you saved the file, then run:

```
certutil -hashfile FreeMyMemory.exe SHA256
```

The long code it prints must match the SHA-256 shown in the release notes. If it doesn't, delete the file and don't run it.

## Requirements

Windows 10 (version 1809 or newer) or Windows 11, 64-bit.
